# Auxiliary MRF benchmark and BO pilot

## Why add an MRF?

The project succeeds by **characterizing where methods work and fail**, not by inventing a novel optimizer. The core Phase 2 bank contains 24 continuous 2D/3D landscapes. This adds one explicitly separate discrete system to test whether conclusions transfer to structured configuration spaces.

A Markov random field (MRF) is a probability model over variables on an undirected graph. Given a node’s neighbors, that node is conditionally independent of non-neighbors. A pairwise MRF factorizes into node and edge potentials:

p(s) = (1/Z) product_i psi_i(s_i) product_(i,j) psi_ij(s_i,s_j)

For an Ising model, spins s_i are -1 or +1 and the score is g(s) = sum_(i,j in E) J_ij s_i s_j + sum_i h_i s_i. Positive J rewards equal neighbors; negative J rewards opposite neighbors; h biases a node. Mixed-sign loops create frustration, so all pairwise preferences cannot necessarily be satisfied at once. Since p(s) is proportional to exp(g(s)), maximizing g gives the MAP configuration.

The 3x3 grid has 9 binary variables and 2^9 = 512 states, so we can enumerate the exact MAP value for scoring. BO searches the configuration-to-score function; it is not being used to infer the MRF distribution. The generic RBF GP in this pilot sees a flattened 9-bit vector and ignores graph adjacency—an important limitation to characterize.

## Pilot protocol

Run from repository root with: MPLBACKEND=Agg python -m experiments.mrf_bo_pilot. It compares finite-catalogue GP-UCB with uniform random search on four systems: 2D quadratic peak, 2D competing peaks, 2D hidden narrow peak, and the 3x3 binary Ising MRF. Each policy shares the same six starting points for a given seed; there are 10 paired seeds and 30 total objective evaluations. GP-UCB uses a fixed RBF length scale of 0.18 for continuous cases and 1.35 for MRF, beta=2, standardized observations, and 1e-6 jitter. Observations are noiseless. These are fixed settings, not fitted or sensitivity-tested hyperparameters.

The evaluator computes the optimum and range of the finite candidate catalogue, but the acquisition only sees queried labels. Normalized regret = (catalogue best - best queried)/(catalogue best - catalogue worst). Success means normalized regret <= 0.05 at the 30-evaluation budget. Every run continued to budget; first-hit time is not stopping-rule savings.

## Preliminary results

Mean final normalized regret (SD), 10 seeds:

| System | GP-UCB | Random | Success GP-UCB / Random |
|---|---:|---:|---:|
| Quadratic peak | 0.00002 (0.00008) | 0.01935 (0.01199) | 10/10 / 10/10 |
| Competing peaks | 0.02132 (0.03765) | 0.17837 (0.13747) | 8/10 / 1/10 |
| Hidden narrow peak | 0.32991 (0.00000) | 0.28911 (0.17346) | 0/10 / 2/10 |
| Ising MRF | 0.00743 (0.00753) | 0.11497 (0.06782) | 10/10 / 2/10 |

Full traces and the regret figure are generated by the pilot script; the local files are results/phase3/mrf_bo_pilot/summary.csv, trajectories.csv, and regret_curves.png.

## What this suggests—and does not

GP-UCB did well on the smooth peak, competing peaks, and this one MRF; the hidden narrow peak exposed a failure condition for the fixed surrogate scale. Identical GP-UCB final regret across all 10 hidden-peak seeds suggests this setting repeatedly settled on the broad basin instead of finding the narrow one. This is useful characterization, not a universal ranking.

This is a NumPy exact-GP prototype, not the planned BoTorch implementation. Ten seeds, one fixed MRF, no observation noise, one fixed GP configuration, and finite catalogues are exploratory only. No stopping rule has been tested. Next: reproduce this in BoTorch; vary only length scale on paired runs; then compare stopping rules on complete shared trajectories using regret, success, false-stop rate, and actual evaluation savings. Continuous-grid conclusions apply only to that grid; the MRF catalogue is exhaustive.
